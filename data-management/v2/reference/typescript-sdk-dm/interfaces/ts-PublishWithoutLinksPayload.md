# Interface: PublishWithoutLinksPayload

Defined in: [model/publishWithoutLinksPayload.ts:14](https://github.com/autodesk-platform-services/aps-sdk-node/blob/eeaeb10a079bc82754d05778f6c83dafc47cac8a/datamanagement/source/model/publishWithoutLinksPayload.ts#L14)

An object that contains the input data to execute the PublishWithoutLinks command.
*
* The PublishWithoutLinks command publishes the latest version of a Collaboration for Revit (C4R) model without the links it contains to BIM 360 Docs. See the [Developer’s Guide topic on the PublishWithoutLinks command](https://aps.autodesk.com/en/docs/data/v2/developers_guide/commands/publishwithoutlinks/) for more information.
