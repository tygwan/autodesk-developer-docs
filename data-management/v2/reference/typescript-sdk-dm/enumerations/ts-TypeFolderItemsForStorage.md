# Enumeration: TypeFolderItemsForStorage

Defined in: [model/typeFolderItemsForStorage.ts:13](https://github.com/autodesk-platform-services/aps-sdk-node/blob/eeaeb10a079bc82754d05778f6c83dafc47cac8a/datamanagement/source/model/typeFolderItemsForStorage.ts#L13)

The type of resource the storage location is related to. Possible values are:
*
* - `folders` - The storage location is for a new item.
* - `items` - The storage location is for a new version of an existing item.
