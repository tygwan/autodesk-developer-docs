# Enumeration: Region

Defined in: [model/region.ts:13](https://github.com/autodesk-platform-services/aps-sdk-node/blob/eeaeb10a079bc82754d05778f6c83dafc47cac8a/datamanagement/source/model/region.ts#L13)

Specifies where the hub is stored. Possible values are:
*
* - `US` - Data center for the US region.
* - `EMEA` - Data center for the European Union, Middle East, and Africa regions.
* - `APAC` - Data center for the Australia region.
