# Enumeration: NestedXref

Defined in: [model/nestedXref.ts:12](https://github.com/autodesk-platform-services/aps-sdk-node/blob/eeaeb10a079bc82754d05778f6c83dafc47cac8a/datamanagement/source/model/nestedXref.ts#L12)

The type of the xref, which defines how nested xrefs are handled. Possible values are:
*
* - `attachment`: Nested xrefs are not ignored.
* - `overlay` : Nested xrefs are ignored.
