# Enumeration: MetarefsDirection

Defined in: [model/metarefsDirection.ts:12](https://github.com/autodesk-platform-services/aps-sdk-node/blob/eeaeb10a079bc82754d05778f6c83dafc47cac8a/datamanagement/source/model/metarefsDirection.ts#L12)

Describes the direction of data flow in the relationship. Possible values are:
*
* - `to` - Data flows from this resource to the related resource.
* - `from` - Data flows from the related resource to this resource.
