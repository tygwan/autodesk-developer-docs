# Code Samples

## Extract Revit properties

[https://github.com/autodesk-platform-services/aps-extract-spreadsheet](https://github.com/autodesk-platform-services/aps-extract-spreadsheet)

This code sample demonstrates using the Model Derivative API to extract properties from a Revit file. It then generates an Excel Spreadsheet, where each sheet will contain one type/category of objects.

`Node.js`, `Model_Derivative_V2`

## Translate a model for display with the Viewer SDK (Node.js)

[https://github.com/autodesk-platform-services/aps-simple-viewer-nodejs](https://github.com/autodesk-platform-services/aps-simple-viewer-nodejs)

This code sample demonstrates a web application utilizing modern web technologies such as HTML5, JavaScript, and CSS. It is part of the [Simple Viewer Getting Started tutorial](https://get-started.aps-dev.autodesk.com/tutorials/simple-viewer/), which illustrates how to display a model in a web browser. The sample uses the Model Derivative API and implements a route that initiates a translation job to convert a model to the SVF2 format.

`Node.js`, `Model_Derivative_V2`

## Translate a model for display with the Viewer SDK (.NET)

[https://github.com/autodesk-platform-services/aps-simple-viewer-dotnet](https://github.com/autodesk-platform-services/aps-simple-viewer-dotnet)

This code sample demonstrates a web application utilizing modern web technologies such as HTML5, JavaScript, and CSS. It is part of the [Simple Viewer Getting Started tutorial](https://get-started.aps-dev.autodesk.com/tutorials/simple-viewer/), which illustrates how to display a model in a web browser. The sample uses the Model Derivative API and implements a route that initiates a translation job to convert a model to the SVF2 format.

`.NET`, `C#`, `Model_Derivative_V2`

## Translate models uploaded to buckets (WPF)

[https://github.com/autodesk-platform-services/bucket-manager-wpf](https://github.com/autodesk-platform-services/bucket-manager-wpf)

This code sample demonstrates a Windows desktop application that lists all the buckets for a specified Client ID and Client Secret combination. You can create new buckets, upload files to a bucket, and much more, It uses the Model Derivative API to translate uploaded models.

`.NET`, `C#`, `WPF`, `Model_Derivative_V2`

## Translate models uploaded to buckets (Node.js)

[https://github.com/autodesk-platform-services/aps-buckets-tools](https://github.com/autodesk-platform-services/aps-buckets-tools)

This code sample is a Node.js based bucket management tool. It lets you create buckets, upload models to a bucket, and so on. It uses the Model Derivative API to translate uploaded models and query metadata from them. It also demonstrates how to use the Model Derivative API to extract geometry from a model.

`Node.js`, `Model_Derivative_V2`

## Translate Revit files to IFC

[https://github.com/autodesk-platform-services/aps-revit.ifc.scheduler](https://github.com/autodesk-platform-services/aps-revit.ifc.scheduler)

This code sample demonstrates the use of the Model Derivative API to convert a Revit file stored in Forma or BIM 360 to the IFC format.

`.NET`, `C#`, `Model_Derivative_V2`
