# Enumeration: OutputType

The requested output types. Possible values include `svf`, `svf2`, `thumbnail`, `stl`, `step`, `iges`, `obj`, `ifc` or `dwg`. For a list of supported types, call the [List Supported Formats](https://aps.autodesk.com/en/docs/model-derivative/v2/reference/typescript-sdk/classes/ModelDerivativeClient/#getformats) operation.
