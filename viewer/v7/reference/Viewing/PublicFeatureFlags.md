# PublicFeatureFlags

## new PublicFeatureFlags()

List of publicly available feature flags.

# Properties

| DSEndpointsboolean | Defines whether automatic region routing is enabled (Default OFF) |
| --- | --- |
| LargeModelExperienceboolean | Defines whether optimizations for working with large models are activated (Default ON) |
| SlowGpuDetectionboolean | Defines whether users are notified that they use a slow graphics card (Default OFF) |
| SceneAPIboolean | Defines whether the Scene API feature is active for all models (Default OFF) |
| WebGPUboolean | Defines whether the WebGPU renderer can be activated in the settings panel (Default ON) |
