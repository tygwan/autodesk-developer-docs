# Filterbox

## new Filterbox(id, options)

A text input that invokes a callback when the text changes.

### Parameters

| idstring | The id for this control. |
| --- | --- |
| optionsobject | An optional dictionary of options. |
| filterFunctionfunction | Invoked when the text changes, receives 1 string argument. |
