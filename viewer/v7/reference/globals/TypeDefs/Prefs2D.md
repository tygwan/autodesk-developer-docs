# Prefs2D

Contains viewer setting preference names for 2D models.

# Properties

| GRAYSCALEstring | Overrides line colors in 2D models to render in shades of gray. |
| --- | --- |
| SWAP_BLACK_AND_WHITEstring | Will switch to white lines on a black background. |
| SCREEN_SPACE_LINE_WIDTHstring | PDF-only: keeps line thickness constant on screen as you zoom (relative widths preserved). |
| FORCE_PDF_CALIBRATIONstring | Force PDF calibration before measuring. |
| FORCE_LEAFLET_CALIBRATIONstring | Force Leaflet calibration before measuring. |
| VECTOR_VIEWINGstring | Vector viewing of PDF. |
