# AttributeLayout

Describes one attribute within an interleaved vertex buffer.

# Properties

| offsetnumber | Start position (in floats) of this attribute within one vertex stride. |
| --- | --- |
| itemSizenumber | Number of components per vertex (e.g. 3 for xyz positions). |
| bytesPerItemnumber | Bytes per component (default 4, i.e. float32). |
| normalizedboolean | Whether integer data should be normalized to [0,1]. |
