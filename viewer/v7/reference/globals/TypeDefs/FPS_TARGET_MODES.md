# _TARGET_MODES

Modes to set the FPS target when progressive rendering is enabled.

# Properties

| LOWnumber | sets the FPS target to 6. |
| --- | --- |
| MODERATEnumber | sets the FPS target to 15. |
| MEDIUMnumber | sets the FPS target to 30. |
| HIGHnumber | sets the FPS target to 60. |
