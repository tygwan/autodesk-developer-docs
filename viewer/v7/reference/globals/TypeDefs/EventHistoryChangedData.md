# EventHistoryChangedData

The event data to identify the action and target for MarkupCore.EVENT_HISTORY_CHANGED event.

# Properties

| actionstring | A string identifier for the action taken, like redo, undo, cancel, execute, clear |
| --- | --- |
| targetIdnumber | A number targetId based on the action. |
