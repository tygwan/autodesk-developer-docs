# VertexAttributeReader

Reads a decoded vertex attribute (e.g. position or normal) for a single vertex into the provided output vector.

## Parameters

| index*number | The index of the vertex to read. |
| --- | --- |
| out*[Vector3](https://aps.autodesk.com/en/docs/viewer/v7/reference/Math/Vector3/) | The vector that receives the decoded attribute components. |
