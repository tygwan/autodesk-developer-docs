# NavToolsConfig

Configuration object for the navigation tools

# Properties

| dollyScrollScalenumber | **Deprecated** Please, use `zoomScrollSpeed` viewer setting instead. The dolly (zoom) scale of the scroll wheel which is used to calculate the camera distance. The default is set to 0.6. |
| --- | --- |
| dollyDragScalenumber | **Deprecated** Please, use `zoomDragSpeed` viewer setting instead. The dolly (zoom) scale for the zoom tool which is used to calculate the camera distance. The default is set to 100. |
