# GetPropertiesResult

Object with properties associated with a dbId.

# Properties

| dbIdnumber | the id passed into [getProperties](https://aps.autodesk.com/en/docs/viewer/v7/reference/Viewing/Model/#getProperties/) function. |
| --- | --- |
| externalIdstring | an identifier that can be used in the un-translated version of the model. Can be used for desktop application integrations. |
| namestring | The element’s name. |
| propertiesArray.<PropertyResult> | list of associated properties |
