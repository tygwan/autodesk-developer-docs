# LMV_VECTOR_PDF

When true, the viewer will favor loading the PDF file over the Leaflet derivative, ignoring the manifest value for `totalRasterPixels`. A true value will take precedence over [LMV_RASTER_PDF](https://aps.autodesk.com/en/docs/viewer/v7/reference/globals/Properties/LMV_RASTER_PDF/).
