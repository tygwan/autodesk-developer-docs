# LMV_THIRD_PARTY_COOKIE

When true, requests to APS are authenticated with a cookie. When false, requests to APS are authenticated with an Authentication header. When undefined, the viewer will first try authentication via cookie, if that doesn’t work it will fallback to using an Authentication header.
