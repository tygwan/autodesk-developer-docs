# DownloadInfo

![object](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/badge_object.png)

Represents information required to download geometry data from a URL.

## Fields

| url*[String!](https://aps.autodesk.com/en/docs/aecdatamodel/v1/reference/scalars) `non-null` | The URL from which the geometry data can be downloaded. |
| --- | --- |
| objectId*[ID!](https://aps.autodesk.com/en/docs/aecdatamodel/v1/reference/scalars) `non-null` | The object ID associated with the download. |
