# PrimitiveType

![enum](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/badge_enum.png)
Enum which represents the possible types of a Primitive.

## Valid Values

| Value | Description |
| --- | --- |
| CURVE | Curve Type |
| POINT | Point Type |

## Where Used

| Object/Input | Field | Description |
| --- | --- | --- |
| [GeometryPrimitive](https://aps.autodesk.com/en/docs/aecdatamodel/v1/reference/objects/geometryprimitive) | `type`. | Represents a Geometry Primitive which can be a Curve or a Point. |
