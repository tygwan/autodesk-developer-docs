# GeometryComponentType

![enum](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/badge_enum.png)

## Valid Values

| Value | Description |
| --- | --- |
| PRIMITIVE | Primitive Type |
| BINARYDATA | Binary Data Type |
| INSTANCE | Instance Type |
