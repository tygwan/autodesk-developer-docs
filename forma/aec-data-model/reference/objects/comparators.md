# Comparators

![enum](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/badge_enum.png)
Valid comparators when filtering by a value

## Valid Values

| Value | Description |
| --- | --- |
| CASE_SENSITIVE | Case sensitive |
| CONTAINS | Contains |
| STARTS_WITH | Starts with |
| ENDS_WITH | Ends with |
| GREATER_THAN | Greater than |
| LESS_THAN | Less than |
| GREATER_THAN_EQUAL_TO | Greater than or equal to |
| LESS_THAN_EQUAL_TO | Less than or equal to |
| NOT_EQUAL | Not equal to |

## Where Used

| Object/Input | Field | Description |
| --- | --- | --- |
| [valuecomparatorinput](https://aps.autodesk.com/en/docs/aecdatamodel/v1/reference/inputs/valuecomparatorinput) | `comparator`. | Comparator to apply |
