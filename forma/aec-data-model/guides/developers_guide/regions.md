# Regions Support

AEC Data Models are hosted on the Forma platform across multiple regions. The following table lists the currently supported regions.
The GraphQL access URL is common for all regions [https://developer.api.autodesk.com/aec/graphql](https://developer.api.autodesk.com/aec/graphql).

| Regions | API Value | Location |
| --- | --- | --- |
| United States | US | AWS US-East |
| Europe | EMEA | AWS Ireland |
| Australia | AUS | AWS Sydney |
| India | IND | AWS Mumbai |
| United Kingdom | GBR | AWS London |
| Germany | DEU | AWS Frankfurt |
| Canada | CAN | AWS Central |
| Japan | JPN | AWS Tokyo |

For more information about specifying region in the header, see [Regions Supported](https://aps.autodesk.com/en/docs/aecdatamodel/v1/reference/graphqlendpoint).
