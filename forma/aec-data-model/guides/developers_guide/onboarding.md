# Onboarding to AEC Data Model

This topic outlines the requirements to get started with onboarding. If you have a Forma Data Management subscription, you can enable your Forma Hub to extract data to AEC Data Model at no additional cost. Access to this functionality is being rolled out and will be available in the account settings in the coming days for you to enable.

## Activate your Forma Hub to extract data to AEC Data Model

Enable your Forma Hub for AEC Data Model by performing the following steps:
- Log on to the [Forma website](https://acc.autodesk.com/projects) .
- You can access the **Account Admin Settings** page in the following two ways:  From the Forma Home page, click **Account Admin**.  ![../../../_images/forma-admin1.png](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/forma-admin1.png) Click **Settings** to access the **Account Admin Settings** page. ![../../../_images/forma-admin4.png](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/forma-admin4.png)
- From the Forma Data Management page, if you have access to Forma Data Management, click **Settings** to access the **Account Admin Settings** page.  ![../../../_images/forma-admin2.png](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/forma-admin2.png)
- On the **Account Admin Settings** page, locate the **Activate** button. It is not in the activated state by default.  ![../../../_images/forma-activ-switch.png](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/forma-activ-switch.png)
- Click the **Activate** button to enable the AEC Data Model capabilities for your account.  ![../../../_images/forma-switch-enabled.png](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/forma-switch-enabled.png)

### Offboarding

If you don’t want to extract your data to the AEC Data Model, contact the Support Team through [https://aps.autodesk.com/get-help](https://aps.autodesk.com/get-help).
