# Before You Begin

## Step 1: Prerequisites
- Make sure that you have enabled your Forma Hub for extraction to the AEC Data Model. For more information, refer [AEC Data Model Onboarding](https://aps.autodesk.com/en/docs/aecdatamodel/v1/developers_guide/onboarding).
- Make sure you are working with Revit files that are version 2024 or later.
- Make sure that you have a Forma Data Management license and are using the AMER, EMEA or AUS instance of your Forma Hub.
- Make sure you have access to the necessary files in your Forma project.
- Make sure you select the **AEC Data Model API** and **Data Management API** services to use the AEC Data Model API.

## Step 2: Register an App
- If you haven’t registered an app for the AEC Data Model API, refer to the tutorial [Create an App](https://aps.autodesk.com/en/docs/oauth/v2/tutorials/create-app/) for step-by-step instructions.
- Provide access to your client ID in your Forma Hub by following the steps mentioned in the [Provisioning access in other products](https://get-started.aps.autodesk.com/#provision-access-in-other-products) page.

## Step 3: Setting up the environment

If you are using this API for the first time, we recommend that you [configure your environment](https://get-started.aps.autodesk.com/setup/). For more learning resources, you can see [Tutorials](https://get-started.aps.autodesk.com/tutorials/simple-viewer).

- Sign in with your Autodesk registered user credentials.  After logging in, you will see the explorer interface as shown below: [![../../../_images/beforeubegin.png](https://developer.doc.autodesk.com/bPlouYTd/forge-aim-graphql-docs-main-695451/_images/beforeubegin.png)](https://aecdatamodel-explorer.autodesk.io/)

## Step 6: Next steps

For an enhanced learning experience, it is advisable to begin with the [Getting Started](https://aps.autodesk.com/en/docs/aecdatamodel/v1/tutorials/before_you_begin/aps.autodesk.com/en/docs/aecdatamodel/v1/tutorials/tutorial01/) section before moving on to the [Working with Advanced Queries](https://aps.autodesk.com/en/docs/aecdatamodel/v1/tutorials/before_you_begin/aps.autodesk.com/en/docs/aecdatamodel/v1/tutorials/tutorial02/) section. Following this recommended learning path will facilitate smoother progress throughout the course.

When you are ready for specialized workflows, use [Retrieve Geometry Data](https://aps.autodesk.com/en/docs/aecdatamodel/v1/tutorials/geometry/geometry_query) for geometry queries and exports, and [Extensibility of Element Data](https://aps.autodesk.com/en/docs/aecdatamodel/v1/tutorials/extend_element_data/create_property_definition) for custom properties on elements.
